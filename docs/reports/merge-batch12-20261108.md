- `lane-fd207`, tip `53e81498c` — one-line fix: the multisample-texture
  error handler now uses the value passed into it, so a driver refusal is
  reported and the session continues instead of dying on an uncaught
  ReferenceError. Record `docs/reports/fd207-multisample-catch-20261108.md`.
  Queue pipeline 63 standard (native 705/0 + 120/0).
- `lane-fd263`, tip `dee45bd07` — the Direct3D 10 comprehensive test
  failed on the shipped build with an uncaught WebAssembly error about
  unaligned access while starting its next program. Root cause, proven by
  a symbols build plus function matching against the shipped build: a
  guest thread's emulator stack overflowed its 64 KiB limit during
  process teardown, grew past the guard into the thread's own
  thread-local-storage key slots, and corrupted the proxying-context
  list pointer to a small integer; at thread exit the lock attempt on
  that bogus node tripped the alignment trap. Fix: raise the thread
  stack to 512 KiB (`-sDEFAULT_PTHREAD_STACK_SIZE=524288` on the
  wasm64-mt target). Record `docs/reports/fd263-stack-overflow-20261108.md`.
  Queue pipeline 64 standard (native 705/0 + 120/0).
