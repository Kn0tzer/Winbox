# Cold-start measurement, 64-bit — 2026-11-07 (lane-coldstart-x64)

## What was measured

A 64-bit cold start: a first-time visitor opening the shipped session page
in a brand-new browser profile, with the launcher's restart budget
pre-exhausted (bwretry=2), so the first attempt is what is measured and no
start is a rescue. A boot counts as certified only under the hardened rule:
the page itself reports ready, the desktop's window handle is the plausible
genuine handle, and the desktop program's start signal is present in the
session console. Apparatus: `test-results/coldstart-x64/live-driver.mjs`
driven by `run-boot.sh`, the locally built copy served on 127.0.0.1 by the
project's own static server (`serve-dist.mjs`).

## Supersession

This record supersedes the earlier unverified sampling from this lane's
first attempt. That sampling never counted: its build
(`test-results/coldstart-x64/build-base.log`) was killed mid-run
(SIGTERM), its log carries no "Browser export verified" line, and it ends
"BUILD COMPLETE not claimed" — no verified build ever existed for it, so
any numbers taken from it were measurements of an unverified copy. The
measurement above is the first completed cold-start series on a verified
build of the current tip.

## Outcome

No new defect found and nothing filed: on the current tip, 64-bit cold
starts certify first-try, 6 of 6, with the same per-session console census
the shipped build shows. The cold-start defect stays closed on the
strength of its earlier live proof; this series is a local-serving
confirmation at the same build identity, not a reopening.
