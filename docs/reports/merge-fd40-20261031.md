## What the fix is

FD-40: sessions in the boot-smoke shape never reached a window
station. Root cause: the staged win32u.dll (from-source Wine-8
backport rebuild) lacked the 32-byte "Wine builtin DLL" signature
at file offset 64, so wineserver flagged it `image_flags 0x04`
instead of `0x44`, the syscall table never registered, and
user32 initialisation silently no-opped. The fix
(`5e4bab8f2`) makes `tools/rootfs64/build-wine8-backports.sh`
stamp every rebuilt DLL the way winebuild's
`make_builtin_files` does, and stamps the shipped win32u.dll in
place (sha `49b87438…`, size unchanged, code bytes untouched).
