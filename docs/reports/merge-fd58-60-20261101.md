  native **665/665 + 64/64** with the lane's new test line
  present in both suites.
- **Settlement 2, first attempt (`62c491eb6`):** `#include
  UNISTD` added to kprocess.cpp — the codebase's own
  pattern (fs.cpp, fsfilenode.cpp, loader.cpp). **Gate
  run 2's dist build failed in 14 s with a second-order
  error** (`dist-build2.log`): musl's unistd.h `#define`s

  (`docs/reports/fd58-fd60-kernel-semantics-20261101.md`):
  FD-58 is closed by CL-30 (chmod/fchmod/fchmodat apply the

  fchmodat dispatch case was missing and is added; NOFOLLOW
  on a symlink returns the host's measured ENOTSUP; the
  stored mode is guest-visible state only). FD-60 is
  closed by CL-31 (link() creates a true hard link — a
  second node sharing the source's inode id, content
  identity via a real host link between the native paths,
  link-group counts and Linux name-semantics event
  fan-out; non-host-file sources are refused with EPERM
  and a BW64-FAIL line instead of being silently copied).

  half (IN_ACCESS implemented for completed reads
  delivering >0 bytes — KObject-layer reads, 64-bit

  mmap-write IN_MODIFY proven NOT-A-GAP — the host kernel
  generates none under any measured ordering, and the
  emulator matches by generating none). FD-79
