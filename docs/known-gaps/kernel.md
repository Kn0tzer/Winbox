# Kernel and syscall gap register

Audit baseline: Linux 6.12 x86-64 syscall ABI (`arch/x86/entry/syscalls/syscall_64.tbl`, common and 64-bit entries numbered 0–450), plus the owned kernel, I/O, and non-CPU memory/page-protection paths. `syscall64.cpp` now sends unknown and explicit unimplemented x64 syscall numbers through one once-per-number warning and `-ENOSYS` helper; the native source-scanning guard is `source/test/process/testSyscall64DispatchGuard.cpp`. The audit of all owned paths is in progress; open rows below remain actionable and must receive a final disposition before this register is complete.

## Dispatch audit

The x64 dispatch has one default branch, which now calls `unimplementedSyscall64(nr)` and returns `-ENOSYS`. Explicit known unimplemented numbers select that same helper. The table-name map was generated from Linux v6.12's `syscall_64.tbl` common and 64 ABI rows (363 entries, 0–450); this table's unhandled entries still need to be enumerated and given an individual implementation or loud-rejection disposition as the remaining audit proceeds.
