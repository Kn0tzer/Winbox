# Test entrypoints

[The test catalog](CATALOG.md) maps each subsystem and 32/64-bit architecture
to maintained checks, commands and known gaps. Run `npm test` for legacy Node
and suite unit checks; native and browser checks have separate entrypoints.

[Suite](suite/README.md), [system diagnostics](diagnostics/README.md),
[recovered regressions](../../tools/regression/README.md) and
[historical reports](../../docs/reports/README.md) retain the existing tests
and evidence.
